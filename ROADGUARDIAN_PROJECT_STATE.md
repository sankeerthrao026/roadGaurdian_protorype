## Authority Alert + Incident Response Workflow

### Feature
Automatic real-time authority alert generation and emergency response workflow triggered upon confirmed traffic incidents.

### Trigger
Triggered automatically when the existing computer vision & analytics pipeline (`CameraWorker._execute_final_analysis` / `IncidentStore.upsert_incident`) confirms an incident with non-monitoring status and calculated ML severity score.

### Alert Data
- `alert_id`: Unique identifier (e.g. `ALERT_CAM03_001`).
- `incident_id`: Linked incident identifier (e.g. `CAM03_001`).
- `incident_type`: Classified incident type (`ROLLOVER`, `COLLISION`, `FIRE/SMOKE`).
- `severity_label`: Categorical severity (`Low`, `Medium`, `High`, `Critical`).
- `severity_score`: Continuous numerical score [0–100] from ML regressor.
- `camera_id`: Originating CCTV camera ID (`CAM-03`).
- `road_name`: Highway corridor / location name (`170 Freeway Southbound, Oxnard St Exit`).
- `location`: Structured GPS coordinates (`lat: 34.1808, lon: -118.3908`).
- `timestamp`: Formatted event timestamp.
- `authorities`: Array of assigned emergency response services.
- `status`: Lifecycle state (`GENERATED` → `ACKNOWLEDGED` → `RESOLVED`).
- `badge`: Explicit prototype attribution (`DISPATCH SIMULATED`).
- `created_at`: ISO creation timestamp.
- `acknowledged_at`: ISO acknowledgement timestamp.

### Dashboard Notification
Implemented in `AuthorityAlertBanner.tsx`:
- Prominent emergency bulletin styled with restrained architectural borders and emergency indicators.
- Displays incident summary, GPS location, camera ID, severity score, timestamp, and mapped response authorities.
- Provides immediate action controls: `[ VIEW INCIDENT DOSSIER ]`, `[ ACKNOWLEDGE ALERT ]`, `[ DISMISS ]`.

### Alert Sound
Implemented in `frontend/src/utils/sound.ts`:
- **Type:** Synthesized emergency buzzer / warning alarm using HTML5 Web Audio API.
- **Character:** Sustained siren-like warning tone with rising/falling frequency (460 Hz ↔ 760 Hz) and multi-oscillator harmonic layering (Sawtooth + Square + Triangle).
- **Duration:** ~1.25 seconds (2 continuous warning sweep cycles).
- **No Beeps:** Continuous frequency modulation with zero stuttering or rapid on/off beeping.
- **Deduplication:** Guarded by `playedAlertIds` on frontend and unique `alert_id` on backend (ONE INCIDENT = ONE ALERT = ONE SOUND).
- **Audio Unlock:** Audio context automatically unlocked on initial user gesture (`pointerdown`, `keydown`, or PLAY button).

### Deduplication
- Single-event tracking: **ONE INCIDENT = ONE ALERT = ONE SOUND**.
- Deduplicated on frontend via `playedAlertIds` set and on backend via unique `alert_id` in `IncidentStore`.
- Continuous playback across subsequent frames and video looping does not re-trigger alerts for the same incident.

### View Incident Navigation
- Clicking `[ VIEW INCIDENT DOSSIER ]` focuses the matching incident object in application state and smoothly scrolls into the `DetailInspector` interface.

### Incident Detail Interface
Preserves the existing `DetailInspector` interface with all 6 tabs intact:
1. `OVERVIEW`: Incident confirmation card, vehicle/person/fire/rollover flags, and evidence timeline.
2. `SEVERITY & SHAP`: Numerical gauge, classification tier, and SHAP feature attribution bar chart.
3. `RESPONSE`: Simulated emergency dispatch action logs and unit assignments.
4. `FINAL REPORT`: Markdown/HTML compliance report generated by LangGraph `ReportAgent`.
5. `RAG CONTEXT`: Historical similar accident logs queried from ChromaDB vector store.
6. `PERFORMANCE`: Real-time video FPS, AI FPS, frame counters, and processing durations.

### Response Authorities Mapping
- **Critical / High Collisions & Rollovers:** Highway Patrol & Traffic Enforcement, Emergency Medical Services (EMS) / Trauma Center.
- **Fire & Smoke Events:** Fire & Rescue Department, Chemical Suppression Unit.
- **Medium Severity & Disabled Vehicles:** Highway Patrol & Traffic Control, Roadside Assistance & Towing.

### Dispatch Attribution
- **Classification:** **SIMULATED RESPONSE / DISPATCH SIMULATED**.
- Clearly marked on UI badges and dispatches; no real 911 CAD API integration is claimed.

### Acknowledgement
- Clicking `[ ACKNOWLEDGE ALERT ]` executes `POST /api/alerts/{alert_id}/acknowledge`.
- Updates alert status from `GENERATED` → `ACKNOWLEDGED`, sets `acknowledged_at` timestamp, and highlights the status badge.
